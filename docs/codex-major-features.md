# Codex の主要機能

このドキュメントは、Codex を日常的に使う際の主要機能を短く把握するための概要です。

## 概要

Codex は、コード実装・調査・検証・修正・自動化を対話的に進めるコーディングエージェントです。CLI や IDE 連携を通じて、既存コードベースを読みながら変更提案や実装を行えます。

## 1. コード生成・編集

- 仕様や要件をもとに新規コードを作成できる
- 既存コードの一部を安全に編集・リファクタリングできる
- 複数ファイルにまたがる変更の提案と適用を支援できる

主な利用場面:

- 新機能のひな形作成
- 定型コードの実装
- 重複コードの整理

## 2. コードベース調査・読解

- プロジェクト内の関連ファイルや定義を横断して探索できる
- 関数や設定の役割、依存関係を説明できる
- 変更影響範囲の洗い出しを支援できる

主な利用場面:

- 初見リポジトリのキャッチアップ
- 不具合箇所の当たり付け
- レビュー前の仕様理解

## 3. デバッグ支援

- エラーメッセージやログから原因候補を整理できる
- 再現手順の仮説を立てて切り分けを進められる
- 修正案と確認観点を提示できる

主な利用場面:

- 実行時エラーの一次切り分け
- 回帰不具合の原因調査
- 修正方針の比較検討

## 4. テスト・検証支援

- 変更に対するテスト観点を整理できる
- 最小限の回帰テスト追加を支援できる
- 差分レビュー時にリスクや見落としを指摘できる

主な利用場面:

- 実装後の確認漏れ防止
- PR前のセルフレビュー
- 既存テスト不足の補強

## 5. 開発作業の自動化

- 反復的な編集・確認手順を対話でまとめて実行できる
- ドキュメント更新や設定変更などの定型作業を効率化できる
- CLI ベースでスクリプトや CI 向けの利用にも展開しやすい

主な利用場面:

- ドキュメント整備
- 設定ファイル更新
- 簡易な保守作業の自動化

## 6. CLI の便利機能（代表例）

- `/status`: セッション状態や使用状況の確認
- `/model`: 利用モデルの切り替え
- `/permissions`: 実行権限ポリシーの確認・変更
- `/diff`: 変更差分の確認
- `/review`: ワーキングツリーのレビュー
- `/compact`: 会話の要約によるコンテキスト整理

## 使い分けの目安

- 実装を進めたい: コード生成・編集 + テスト支援
- 原因を調べたい: コードベース調査・読解 + デバッグ支援
- 作業を早く回したい: 自動化 + CLI 便利機能

## 注意点

- 指示は具体的にすると精度が上がる
- 変更後は必ずテストや差分確認を行う
- 権限が必要な操作（削除・公開・本番影響）は事前確認を行う
