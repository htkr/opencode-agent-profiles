# ranger ガイド

## 目的

このドキュメントは、このリポジトリの開発環境（Devbox）で `ranger` を利用するための最小手順と基本操作をまとめたものです。

## 導入確認（Devbox）

`ranger` は `devbox.json` の `packages` に追加されています。以下で利用可否を確認します。

```bash
devbox run -- ranger --version
```

バージョンが表示されれば利用可能です。

## 起動方法

### カレントディレクトリで起動

```bash
devbox shell
ranger
```

### 指定パスで起動

```bash
devbox run -- ranger /home/htk/project/test
```

## 基本操作

### 移動・開く

- `j` / `k`: 上下移動
- `h`: 親ディレクトリへ移動
- `l` または `Enter`: ディレクトリに入る / ファイルを開く
- `gg`: 先頭へ移動
- `G`: 末尾へ移動

### 表示更新・検索

- `r`: 再読み込み
- `/`: ファイル名検索（インクリメンタル）
- `n` / `N`: 次 / 前の検索結果

### 選択（最低限）

- `Space`: ファイル選択の切替
- `v`: 選択モードの開始
- `V`: 行選択

## 終了方法

- `q`: `ranger` を終了

## よく使うキー一覧（最小）

| キー | 操作 |
|------|------|
| `j` / `k` | 上下移動 |
| `h` / `l` | 親へ戻る / 入る |
| `Enter` | 開く |
| `gg` / `G` | 先頭 / 末尾 |
| `/` | 検索 |
| `n` / `N` | 次 / 前の検索結果 |
| `Space` | 選択切替 |
| `q` | 終了 |

## 設定ファイルの場所（参考）

初期設定を生成したい場合は以下を実行します。

```bash
ranger --copy-config=all
```

一般的な設定ファイルの配置先:

- `~/.config/ranger/rc.conf`
- `~/.config/ranger/rifle.conf`
- `~/.config/ranger/scope.sh`

## 注意点

- `ranger` はターミナル上で動作するため、端末のキーバインド設定と競合する場合があります。
- ファイルを開く動作は環境の設定（`rifle.conf` や関連コマンド）に依存します。
- 削除や移動などの操作は可能ですが、このガイドでは安全のため詳細説明を省いています。
